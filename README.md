## Project Overview
This is a multi-page website project developed for ITMS 205.  
The website allows users to view doctors, book appointments, and explore services offered.

### Features:
- Home Page (`index.html`)  
  - Welcome section
  - Quick booking button
  - Overview of services
  - Doctors table with images, specialties, and experience

- Booking Page (`booking.html`)  
  - Appointment form with fields:
    - Full Name
    - Phone Number
    - Email
    - Age
    - Doctor selection
    - Date & Time
    - Gender
    - Notes

- Products Page (`products.html`)  
  - List of services/features
  - Prices and durations (can be displayed as a table or list)
