## Project Overview
This project is a multi-page website developed for ITMS 205.  
The website allows users to view doctors, book appointments, and explore medical services بسهولة.

---

## Features

### Home Page (`index.html`)
- Welcome section  
- Quick booking button  
- Overview of services  
- Doctors table with images, specialties, and experience  

---

### Booking Page (`booking.html`)
- Appointment form including:  
  - Full Name  
  - Phone Number  
  - Email  
  - Age  
  - Doctor selection  
  - Date & Time  
  - Gender  
  - Notes  

---

### Products Page (`products.html`)
- List of medical services  
- Display prices and estimated durations  
- Organized in table or list format  

---

### About Us Page (`about.html`)
- Information about the medical center  
- Vision and objectives  
- Contact and location details  
- Brief description of services  

---

### Style File (`style.css`)
- Styling for all pages  
- Responsive layout and design  
- Navigation bar design  
- Form styling  
- Buttons and hover effects  
- Color theme for medical website  

---

## Conclusion
This project improves the booking process in medical centers by providing an easy-to-use website.  
It helps reduce waiting time, provides clear information, and enhances the overall user experience.
